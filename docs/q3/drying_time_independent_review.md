## 2. 严重问题：方法 22 的"表面硬化 / 干不完"是数值假象

### 2.1 证据

固定 T = 50.0049 °C 的纯水分扩散代理模型，四种离散组合扫描 C∞（单位 h，"未完成"指 200 h 内 max C 仍 > 0.15）：

| C∞ | 顶点型+调和平均（被审方案） N=200 / 800 | 顶点型+Kirchhoff 积分平均 N=200 / 800 | 格心型+调和平均 N=200 / 800 |
|---|---|---|---|
| 0 | 未完成 / 未完成 | 56.604 / 56.604 | 58.539 / 57.322 |
| 0.03 | 未完成 / 未完成 | 56.963 / 56.963 | 57.252 / 57.023 |
| 0.04999 | 58.792 / 57.348 | 57.308 / 57.308 | 57.353 / 57.312 |

关键观察：

1. C∞ = 0 与 0.03 时，被审方案**加密网格也不收敛**——N=200 与 N=800 的末态 C_max 并不趋近，说明这不是分辨率不足，而是格式的结构性缺陷。
2. 同样条件下，另外三种离散全部在 56.6–58.5 h 完成干燥。
3. C∞ = 0.04999（本题实际工况）四种离散一致收敛到 57.3 h 左右，**主答案不受此缺陷影响**。

（代理模型忽略前几小时预热，故绝对值比完整耦合模型的 57.47 h 略短，用于横向对比离散格式是等价的。）

### 2.2 机理

顶点型网格把节点放在 r = R 上，Robin 条件将该节点值 C_s 拉向 C∞。退化扩散系数 D = D₀e^{-0.45/C} 在 C_s → 0 时坍塌到 0，界面调和平均 ≈ 2D_s 随之归零，**表面半控制体与内部被完全解耦**：流入为 0、流出 h_m(C_s − C∞) 也为 0，水分再也无法离开。任意 N 下这都是方程的不动点，因此加密无效。

连续问题中通量由 Kirchhoff 势 Φ(C) = ∫₀^C D dc 控制。Φ(0) 有限，表面边界层只是变薄而积分阻力保持有界，故干燥不会停滞。调和平均在 D 沿单元指数变化时给出 ≈2D_min，而正确的界面系数是 [Φ(C₂) − Φ(C₁)]/(C₂ − C₁)（对一维稳态通量精确）。

### 2.3 影响与建议

- 方法 22 的"模型自发复现工业上著名的表面硬化现象""存在最优湿度 C∞ ≈ 0.05，附件 1 恰好落在此处"两条结论**不能写进论文**：case hardening 本身是真实现象，但本模型并不预测停滞，这段论述会被内行评委识破。
- 方法 15 的"必须 N = 800，否则时间误差 24%"同样是调和平均造成的，不是问题固有难度。换成 Kirchhoff 积分平均后，顶点型格式在 **N = 200 即网格无关**（56.604 h，N=800 完全相同），计算量降低约 16 倍。
- 修改成本很低：预先在密网格上数值积分出 Φ(C) 并插值，把 `harm(Dm)` 替换为 `(Φ(C₂)−Φ(C₁))/(C₂−C₁)` 即可，`arith(k)` 不需改（k 只跨 2.3 倍，不退化）。
- 问题 4 引入动边界后网格必须重构、N 不可能取很大，这项改动在那里的收益更大。

## 4. 次要问题

1. **文档与代码不一致**：代码中 `D_f(0.5*(Co+Cn), 0.5*(To+Tn))` 是时间中点取系数（二阶，做法更好），文档方法 11 描述为"后向欧拉 θ = 1"。改文档表述即可。
2. **质量守恒残差的解释过强**：对守恒型有限体积 + 后向欧拉，逐单元方程求和后该残差是恒等式，1×10⁻¹⁹ 验证的是组装与线性求解的正确性，不构成对离散误差或误差累积的检验。方法 20 中"还检验误差是否累积"的说法应弱化。
